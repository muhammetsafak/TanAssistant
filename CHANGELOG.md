# Changelog

All notable changes are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows
[Semantic Versioning](https://semver.org/). The version lives in one place, `[workspace.package]`
of the root `Cargo.toml`; `ui/package.json` carries the same number (the release workflow checks
both, and the tag) and `src-tauri/tauri.conf.json` has no `version` of its own.

## [Unreleased]

## [0.2.1] - 2026-11-10

### Added

- Claude and ChatGPT subscriptions as AI providers: the new Claude Code CLI and Codex CLI
  providers run the `claude` or `codex` command installed and signed in on this computer, so
  summaries and screen descriptions count against the subscription instead of an API key. They
  handle summaries and images, not transcription. Installing and signing in to the CLI is up to
  the user; the provider form says so, and for Codex adds that it can run commands and read files
  inside its read-only sandbox. The app never reads the CLI's sign-in token.

### Changed

- Short audio dropouts reported by the capture backend (on Windows: "A buffer underrun or
  overrun occurred.") no longer raise a warning each time. They are counted per track; only
  when five fall within a minute does a single translated notice appear ("The microphone audio
  had short dropouts; recording continues."), and the end-of-recording toast for it is
  informational rather than an error. The gaps were already filled with silence, so the tracks
  stay in sync.
- A session started without a title is named after its local start time as
  `YYYY-MM-DD-HH-MM-SS` (for example `2026-11-10-09-32-05`) instead of the UTC time. Existing
  titles do not change.

## [0.2.0] - 2026-11-09

### Added

- In-app updates: Tan checks GitHub for a newer version at start and once a day (switchable in
  Settings, on by default) and on demand from Settings. It downloads the update, verifies its
  signature, installs it and restarts. Installing and restarting wait while a recording or
  processing run is active, and no new recording or run starts while an update installs. `.deb`
  installs cannot update themselves and get a link to the release page instead. This version
  must be installed by hand once; later versions arrive through the app.
- Audio on the session detail page: the microphone and system tracks play in sync (each can be
  muted), a transcript line seeks the player to its start, and the tracks download as one mixed
  WAV file.
- Diagnostic log: every operation and error is written with a UTC timestamp to a daily file in
  the `logs/` folder of the data directory (`tan.YYYY-MM-DD.log`), including panics with their
  backtrace. Files older than 45 days are deleted automatically; `TAN_LOG` changes the level.

### Changed

- Releases carry signed updater files (`*.sig`, the macOS `.app.tar.gz`) and a `latest.json`
  manifest; local bundle builds without the signing key turn them off (see
  `docs/releasing.md`).

### Fixed

- Screenshot boxes take the aspect ratio of the captured screen.

## [0.1.0] - 2026-11-09

First version.

### Added

- Recording of a meeting: microphone and system audio on separate tracks, plus the screen frames
  that change (perceptual hash), on Windows, macOS (ScreenCaptureKit, 13.0+) and Linux
  (PulseAudio/PipeWire monitor; X11 and Wayland ScreenCast portal frames).
- Transcription with local whisper (voice activity detection, Vulkan and Metal backends, CPU
  fallback) or OpenAI / Gemini; long recordings are chunked for the cloud.
- Notes (summary, decisions, action items, open questions) generated by the AI provider of your
  choice (OpenAI, Anthropic, Gemini, DeepSeek, Ollama) in the note language you set.
- Credentials management (variables and secrets in the OS keychain), session library with
  search, Markdown export, Turkish and English interface, first-use recording notice.
- Installers: Windows NSIS, macOS `.app` / `.dmg`, Linux `.deb` and AppImage, built by
  `.github/workflows/release.yml` on a `v*` tag.
